# 提示词模板与写作范例

本文件给出：①可直接套用的七段式提示词骨架；②单条 15 秒完整版范例（便利店猫咪店员最终版）；③多段拼接版范例（尾帧承接写法）；④提交前必检清单。

## 一、七段式提示词骨架

```text
# 提示词_完整版_vXX（<作品名> · <时长> 秒）

> 图生视频 / 参考生视频。输入素材：<图片1> = <角色A照片描述>；<图片2> = <角色B照片描述>。
> 用法：把下方【提示词正文】整体复制到提示词框；<图片1> 对应上传 <角色A照片>，<图片2> 对应上传 <角色B照片>。画幅 9:16 竖屏，时长 <N> 秒，单条一次生成。

## 提示词正文

<图片1> 作为 <角色A> 的外貌毛色参考：<真实外观特征，如毛色、斑纹、体型>，保留照片中的真实毛色斑纹。它身穿 <服装>，<初始站位>。

<图片2> 作为 <角色B> 的外貌毛色参考：<真实外观特征>，保留照片中的真实毛色斑纹。它身穿 <同款/其他服装>，<初始站位>。

场景：<中性设计描述>，无任何品牌文字或 logo。<关键道具，无品牌文字>，<环境陈设>。光线为 <主光>，<背景光>。

动作与对白（按时间顺序，一条连续 <N> 秒）：
- <t1>-<t2> 秒：<谁>，<动作>，<表情/语气>，说「<台词原文>」；<同画面内其他人物的并行动作>。
- <t2>-<t3> 秒：……

声线设定（重要，务必区分开）：
- <角色A>：<声线描述，如稚嫩清脆的儿童声线>。
- <角色B>：<声线描述，如成熟稳重的成年女声>。
- <顾客等配角>：<声线描述，如低沉沉稳的成年男声>。

镜头：竖屏 9:16。中景、近景、特写交替；写实质感、柔和景深；无字幕、无水印、无品牌文字、无平台 UI。全程机位连续、场景唯一，禁止出现新的空间或场景跳变。

声音：<BGM 策略，默认"无背景音乐，无 BGM，无配乐">；保留 <对白语言> 对白与 <场景> 环境音效、动作拟音（如 ……）。

生成时长：<N> 秒，单条一次生成。
```

## 二、单条 15 秒完整版范例

这是通过验收的最终版（v07）结构，新案例直接按此骨架填充内容即可。全文见 `../examples/01-便利店猫咪店员-v07.md`。

要点回顾：

- 两个角色各一张参考图，开头说明上传顺序；
- 场景显式声明「同一家便利店内部，自始至终只有这一个场景」「机位连续不切换」；
- 需要走动的角色写「双脚站在地面上」；
- 移动写法是「原地转身、不离开后场、不穿过货架、不出现任何新的货架通道或走廊，同一画面内径直向台前走来」；
- 声线设定单独成段，三声线明确反差；
- 时间轴每段写明动作 + 表情 + 语气 + 台词。

## 三、多段拼接版范例（尾帧承接写法）

适用：总时长超过单条上限，或明确要求分段生成再拼接。

### SEG001（第一段）写法要点

- 结尾必须是**可承接的定格**：最后一句动作停在明确画面（如「英短趴在便当盒上」定格约 1 秒收尾）。
- 文件末尾附「尾帧承接说明」：

```text
## 尾帧承接说明

本段结尾定格为「<定格画面描述>」的画面。生成后用该真实尾帧作为片段二 SEG002 的 0 秒首帧输入，以锁定 <道具外观、店内布局与光位> 完全一致。
```

### SEG002（第二段）写法要点

- 输入素材除角色照片外，**必传 SEG001 真实尾帧**，且放在靠后编号（如 `<图片2>`）。
- 提示词开头声明尾帧的基准地位：

```text
<图片2> 作为本段 0 秒首帧和画面基准：上一段结尾 <角色> <定格画面>。便当盒外观、店内货架与收银台布局、暖黄顶光与右侧冷柜冷白背景光、光位全部以上一张图为准，不得改变。
```

- 0 秒起的动作从首帧延续，不重新描述环境。
- 声音：本段不写 BGM；台词只放本段真实发生的（如 SEG002 只有布偶猫一句致歉）。
- 每段时长都是整数秒，时间轴边界整数化。

### 多段版常见错误（真实案例）

| 错误 | 后果 | 正确写法 |
|---|---|---|
| SEG002 不带 SEG001 尾帧 | 便当盒外观、店内环境两段不一致 | 必传真实尾帧作 0 秒首帧 |
| 顾客「えっ？」写在 SEG002 | 疑惑声与画面错位、声音割裂 | 落在 SEG001 趴便当节拍内 |
| SEG002 开头放「手停在便当上」特写 | 画面突兀、无法与上一段衔接 | 从尾帧定格直接延续 |
| 提示词写「面向 XX 平台」 | 平台绑定、不可通用 | 不写平台名 |
| 时长 9.5/8.5 秒 | 平台无法精确设置 | 全部整数秒 |

## 四、提交前必检清单

逐项核对，任一不满足都要先修：

- [ ] 提示词不含任何平台名/平台 UI 字样
- [ ] 所有时长与时间轴边界均为整数秒
- [ ] 多段版：第二段必传第一段真实尾帧，并声明「以上一张图为准，不得改变」
- [ ] 每句台词/每声反应落在它真实发生的节拍段
- [ ] 走动的角色站在地面上，不站在台面/操作台上
- [ ] 移动路径写明「原地转身、不穿过障碍、同一画面内走向目标」，且声明场景唯一、机位连续
- [ ] 每个发声角色都有独立声线且相互有反差
- [ ] 写「无字幕、无水印、无品牌文字、无平台 UI」
- [ ] 参考图描述写「保留照片中的真实毛色斑纹」
- [ ] 生成参数与提示词一致：模型、时长、比例、参考图顺序
