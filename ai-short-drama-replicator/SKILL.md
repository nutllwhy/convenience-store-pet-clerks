# AI Short Drama Replicator（AI 短剧复刻 Skill）

把一段**已有视频/短剧**复刻成用户自己的版本：剧情结构与节拍不动，角色换成用户提供的真实形象（通常是自家宠物照片），生成分镜表和逐镜头提示词；生成后按抽帧检查与用户反馈迭代提示词，直到成片达标。

参考案例：把「两只柴犬在便利店当店员」的视频复刻为「英短+布偶两只猫当店员」，全程日语对白，15 秒单条生成，提示词迭代 v02→v07 后成片通过。完整复盘见 [case-log.md](references/case-log.md)，最终版提示词见 [examples/01-便利店猫咪店员-v07.md](examples/01-便利店猫咪店员-v07.md)。

## 判断是否适用

- **适用**：用户给出原视频/原作品（或截图），并提供了自己的角色素材（宠物照片、人物照片），要求复刻、角色替换、同款剧情。
- **不适用**：从零原创故事 → 使用 `ai-short-drama-director`；没有复刻对象的单镜头口播或展示视频 → 使用普通视频生成工作流。

## 工作流

```text
收集输入（原作品截图 + 角色照片 + 语言/时长/比例约束）
  → 剧情结构提取（节拍表）
  → 角色映射（原角色 → 用户角色，照片锁定外观）
  → 参数决策（时长整数、比例、单条 vs 多段、模型、声音策略）
  → 提示词写作（七段式）
  → 生成与验收（抽帧检查）
  → 版本化迭代（只改被指出的问题）
```

## 1. 收集输入

- **原作品**：向用户索取原视频，或至少 2 张关键节拍截图（开场、转折、结尾各一）。截图只作剧情结构与调度参考，不作为角色外观参考。
- **角色素材**：每个角色一张清晰照片，用于锁定真实外观特征（毛色、斑纹、体型）。照片只锁定外观，服装/站位由提示词指定。
- **约束确认**：对白语言（如日语）、总时长、画幅比例、是否要字幕、声音偏好（有无背景音乐）。用户没说清时按默认：竖屏 9:16、无字幕、无背景音乐仅对白+音效。

## 2. 剧情结构提取

把原视频拆成**节拍表**：每个节拍 = 一个可见的局面变化（谁做了什么、说了什么、情绪如何）。按时间顺序编号，标注每个节拍的时间区间。

示例（便利店猫咪店员 15s）：

| 时间 | 画面与动作 | 台词/声音 |
|---|---|---|
| 0-2.5s | 英短在收银台后招呼顾客，后场布偶背影整理货架 | 小店员：「いらっしゃいませ！このお弁当、温めますか？」 |
| 2.5-3.5s | 顾客手部触碰便当盒（只露手，不露脸） | 顾客：「はい。」 |
| 3.5-5.5s | 英短点头承诺 | 小店员：「ちょっと待ってくださいね！」 |
| 5.5-8s | 英短趴上便当盒加热；布偶背影转头 | 顾客：「えっ？」 |
| 8-10s | 布偶原地转身走向台前 | 无 |
| 10-12.5s | 布偶抱下英短、致歉 | 大店员：「申し訳ございません、今すぐ温めますね。」 |
| 12.5-15s | 布偶开盖吹气，英短歪头看 | 无 |

## 3. 角色映射

- 明确原角色 → 用户角色的对应关系与职能（主角 / 配角 / 只露局部的角色如顾客手部）。
- 提示词里写「保留照片中的真实毛色斑纹」，不自行想象或泛化外观。
- 多个角色同框时，每个角色一张参考图，按 `<图片1>`、`<图片2>` 编号并在提示词开头说明对应关系与上传顺序。

## 4. 参数决策

- **时长必须是整数秒**：所有视频平台的生成读秒都是整数；不要出现 9.5、8.5 这类小数（会无法在平台上精确设置）。
- **画幅**：默认 9:16 竖屏，按用户指定调整。
- **单条 vs 多段**：
  - 优先考虑**单条一次生成**（如 15 秒）：衔接最丝滑、可以整体配 BGM，且避免跨段的一致性漂移。
  - 必须分段时（超时长或需要独立生成）：每段只承载一个主要节拍，完整台词不跨段截断；**段间必须用上一段的真实尾帧作为下一段的 0 秒首帧**，并在第二段提示词中写「便当盒外观、布局、光位以上一张图为准，不得改变」。
- **模型**：默认选用性价比最高的档位（如 seedance 2.0 fast）。分辨率/清晰度以该模型固定输出为准，无法在生成侧继续调低。
- **声音策略**：
  - 默认「无背景音乐，无 BGM，无配乐；仅保留对白与环境音效、动作拟音」。
  - 单条长段且用户明确要求时，可以写氛围 BGM（音量不压对白）。
  - 多段拼接时各段都不配 BGM，避免拼接处音乐割裂。

## 5. 提示词写作（七段式）

每条提示词按以下顺序组织，缺一不可：

1. **参考图说明**：`<图片N>` 对应哪个角色/素材；外观锁定（毛色斑纹、体型）；服装（如便利店绿色制服帽子+上衣）；初始站位（如"站在收银台后"）。
2. **场景**：中性设计、无任何品牌文字或 logo；关键道具（无品牌文字的便当盒等）；光线（主光+背景光）。
3. **动作与对白**：严格按时间轴顺序写，每段含：谁、做什么动作、什么表情/语气、说什么（原文语言，用引号）；标注开始/结束状态。
4. **声线设定**：每个发声角色独立声线（例：主角=稚嫩童声、前辈=成熟女声、顾客=低沉男声），显式要求声线之间有反差。
5. **镜头**：比例、景别变化（开场中景交代、重拍给近景/特写）、质感与景深。
6. **声音**：对白语言 + 环境音效 + 动作拟音；BGM 策略。
7. **生成时长**：整数秒，写清单条还是分段。

完整模板与可直接套用的范例见 [prompt-template.md](references/prompt-template.md)。

### 提示词铁律（从真实案例沉淀，违反必出问题）

1. **不写平台名**：提示词里不要出现「面向 XX 平台」字样，保持平台无关、可直接复制。
2. **时长整数**：所有分段与时间轴边界都用整数秒。
3. **多段承接用真实尾帧**：第二段必传第一段真实尾帧作 0 秒首帧；道具、布局、光位「以上一张图为准，不得改变」。
4. **声音落位准确**：一句台词/一声疑惑必须落在它真实发生的节拍段里，不能挪到别的段（否则听感割裂）。
5. **站位防穿帮**：需要走动的角色写「双脚站在地面上」，明确禁止站在台面/操作台上——否则模型会让它从台面跳下，出现穿帮。
6. **移动路径防场景跳变**：写「原地转身、不离开当前位置、不穿过货架/走廊，同一画面内径直走向目标」；并显式声明「场景唯一、机位连续、不得跳切、不得出现新的空间」。模型容易把「穿过货架」拍成新的货架通道场景。
7. **声线必须有反差**：多个发声角色必须用不同声线/性别；同类声线会混在一起听不出角色。
8. **无字幕、无水印、无品牌文字、无平台 UI**：写入镜头段。
9. **参考图锁定真实特征**：写「保留照片中的真实毛色斑纹」，防止模型泛化外貌。
10. **版本化迭代**：每次修改递增版本号（v02→v07），只改用户指出的问题，未反馈的部分保持原样。

## 6. 生成与验收

- 提交生成时使用真实参数：模型、时长（整数）、比例、参考图 URL（按提示词中的 `<图片N>` 顺序传入）。
- 生成后**主动抽帧**检查关键节拍段，重点排查：移动/转身/起身段落是否穿帮、是否出现新场景（场景跳变）、道具是否变化（便当盒外观、开合状态）。
- 检查声音：对白是否落在正确节拍、声线是否区分、有无意外背景音乐。
- 交付成片前，用文字列出检查结论与问题时间码；有问题先修提示词再重生成，不直接把问题成片交付。

## 7. 迭代

- 用户反馈 → 定位到具体时间码/具体问题 → 只修改对应提示词段落 → 递增版本号 → 重新生成。
- 每次反馈只解决被指出的问题；已通过的内容保持不变。
- 保留每个版本的提示词文件（`提示词_完整版_vXX_*.md`），便于回溯哪一版改了什么。
