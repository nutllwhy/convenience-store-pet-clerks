# Convenience Store Pet Clerks（便利店宠物店员 Skill）

专门制作**「便利店里宠物当店员」系列**短剧视频：便利店里两只猫猫或狗狗店员接待顾客的 15 秒治愈短片。

核心剧情是固定的招牌节拍：小店员问「要加热便当吗」→ 顾客应诺 → 小店员承诺 → 小店员趴在便当上用自己的身体加热 → 顾客「えっ？」→ 大店员转身救场、抱下小店员致歉 → 开盖吹气收尾。角色换成你提供的宠物照片（猫猫版或狗狗版均可），对白可按你的要求选择语言（默认日语）。

本 Skill 由真实案例沉淀而来：把「两只柴犬在便利店当店员」复刻为「英短（小店员）+ 布偶（大店员）」两只猫版的 15 秒日语短剧，提示词迭代 v02→v07 后成片通过。案例完整复盘与最终版提示词都在仓库内。

当前版本：`1.0.0`

## 它解决什么问题

- 想做「便利店猫店员/狗店员」视频，不知道如何把招牌剧情、角色配置和提示词写对；
- 角色外观漂移（毛色/斑纹不还原）、便当盒与店内环境跨段不一致；
- 提示词写了平台名、时长带小数，换平台就无法直接复制；
- 大店员「穿过货架」被模型拍成新场景（场景跳变）、站在台面上走动穿帮（从台上跳下来）；
- 三个发声角色声线无反差，听不出谁是谁；
- 反复改提示词没有版本管理。

## 工作流

```text
收集输入（宠物照片 + 语言/时长/比例/猫版或狗版）
  → 确定角色配置（小店员/大店员/顾客手部）
  → 套用招牌剧情节拍表
  → 参数决策（时长整数、比例、模型、声音策略）
  → 提示词写作（七段式）
  → 生成与验收（抽帧检查）
  → 版本化迭代（只改被指出的问题）
```

## 招牌节拍（默认 15 秒，可调）

| 时间 | 画面与动作 | 台词/声音 |
|---|---|---|
| 0-2.5s | 小店员收银台后招呼顾客，后场大店员背影整理货架 | 小店员：「いらっしゃいませ！このお弁当、温めますか？」 |
| 2.5-3.5s | 顾客手部触碰便当盒（只露手） | 顾客：「はい。」 |
| 3.5-5.5s | 小店员点头承诺 | 小店员：「ちょっと待ってくださいね！」 |
| 5.5-8s | 小店员趴上便当盒加热；大店员背影转头 | 顾客：「えっ？」 |
| 8-10s | 大店员原地转身走向台前 | 无 |
| 10-12.5s | 大店员抱下小店员、致歉 | 大店员：「申し訳ございません、今すぐ温めますね。」 |
| 12.5-15s | 大店员开盖吹气，小店员歪头看 | 无 |

## 角色配置

| 角色 | 职能 | 声线 |
|---|---|---|
| 小店员（小猫/小狗） | 问询、承诺、趴便当加热 | 稚嫩童声 |
| 大店员（大猫/大狗） | 后场整理 → 救场 → 致歉 → 吹气 | 成熟女声 |
| 顾客 | 应诺、疑惑 | 低沉男声（只露手） |

## 提示词铁律（10 条）

1. 不写平台名；2. 时长整数秒；3. 多段承接用真实尾帧；4. 顾客「えっ？」落在趴便当节拍段；5. 大店员双脚站地面防穿帮；6. 原地转身不穿货架防场景跳变；7. 三角色声线反差；8. 无字幕/水印/品牌文字/平台 UI；9. 参考图锁定真实毛色斑纹；10. 版本化迭代。

详见 `references/case-log.md` 的溯源表（每条铁律对应的用户反馈）。

## 边界

- 本 Skill 只负责**便利店宠物店员题材**：剧情节拍、角色配置、场景设定、提示词生成与迭代；其他题材短剧请使用 `ai-short-drama-director`。
- 平台时长上限、参考图数量、模型能力与计费会变化，提交生成前应读取当前入口的实际设置。
- 抽帧检查只能降低问题概率，不能替代对成片剧情、表演、口型、声音和连续性的逐段观看。
- 公开案例只记录匿名化结构与验收结论，不包含私人照片、真实链接或客户素材。
