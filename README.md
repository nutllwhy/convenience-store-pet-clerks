# AI Short Drama Replicator（AI 短剧复刻 Skill）

把一段**已有视频/短剧**复刻成你自己的版本：剧情结构与节拍不动，角色换成你提供的真实形象（自家宠物、真人或指定形象），产出可直接粘贴到视频平台的分镜与逐镜头提示词；生成后按抽帧检查与用户反馈迭代提示词，直到成片达标。

本 Skill 由真实案例沉淀而来：「两只柴犬在便利店当店员」→ 复刻为「英短+布偶两只猫当店员」的 15 秒日语短剧，提示词迭代 v02→v07 后成片通过。案例完整复盘与最终版提示词都在仓库内。

当前版本：`1.0.0`

## 它解决什么问题

- 有现成视频想复刻成自己的版本，却不知道如何把剧情结构搬到自己的角色上；
- 复刻时角色外观漂移（毛色/斑纹不还原）、道具与场景跨段不一致（便当盒、店内布局各段长得不一样）；
- 提示词里写了平台名、时长带小数，导致换平台就无法直接复制使用；
- 多段拼接时声音割裂（疑惑声放错段）、场景跳变（模型把「穿过货架」拍成新场景）、角色穿帮（从台面上跳下来）；
- 多个发声角色声线无反差，听不出谁是谁；
- 反复修改提示词没有版本管理，改着改着忘了哪版改了什么。

## 工作流

```text
收集输入（原作品截图 + 角色照片 + 语言/时长/比例约束）
  → 剧情结构提取（节拍表）
  → 角色映射（原角色 → 用户角色，照片锁定外观）
  → 参数决策（时长整数、比例、单条 vs 多段、模型、声音策略）
  → 提示词写作（七段式）
  → 生成与验收（抽帧检查）
  → 版本化迭代（只改被指出的问题）
```

## 提示词铁律（10 条，违反必出问题）

1. **不写平台名**——保持平台无关、可直接复制；
2. **时长整数秒**——所有视频平台读秒都是整数，不要 9.5/8.5；
3. **多段承接用真实尾帧**——第二段必传第一段真实尾帧作 0 秒首帧，道具/布局/光位「以上一张图为准，不得改变」；
4. **声音落位准确**——一句台词/一声疑惑必须落在它真实发生的节拍段；
5. **站位防穿帮**——要走动的角色写「双脚站在地面上」，禁止站在台面/操作台上；
6. **移动路径防场景跳变**——写「原地转身、不穿过货架/走廊、同一画面内径直走向目标」+「场景唯一、机位连续、不得跳切」；
7. **声线必须有反差**——每个发声角色独立声线（童声/成熟女声/男声），同类声线会混音；
8. **无字幕、无水印、无品牌文字、无平台 UI**；
9. **参考图锁定真实特征**——写「保留照片中的真实毛色斑纹」；
10. **版本化迭代**——每次修改递增版本号，只改被指出的问题。

## 边界

- 本 Skill 负责**复刻已有作品**的剧情结构、角色映射、分镜与提示词生成及迭代；从零原创故事请使用 `ai-short-drama-director`。
- 平台时长上限、参考图数量、模型能力与计费会变化，提交生成前应读取当前入口的实际设置。
- 提示词结构校验与抽帧检查只能降低问题概率，不能替代对成片剧情、表演、口型、声音和连续性的逐段观看。
- 公开案例只记录匿名化结构与验收结论，不包含私人照片、真实链接或客户素材。
