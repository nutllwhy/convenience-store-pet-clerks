# Convenience Store Pet Clerks（便利店宠物店员 Skill）

专门制作**「便利店里宠物当店员」系列**短剧：两只猫猫店员或狗狗店员在便利店里接待顾客。核心剧情是固定的招牌节拍——小店员问「要加热便当吗」→ 顾客应诺 → 小店员承诺 → 小店员趴在便当上用自己的身体加热 → 顾客「えっ？」→ 大店员转身救场、抱下小店员致歉 → 开盖吹气收尾。角色换成用户提供的宠物照片（猫猫版或狗狗版均可），全程可按用户指定语言对白（默认日语）。

参考案例：把「两只柴犬在便利店当店员」复刻为「英短（小店员）+ 布偶（大店员）」两只猫版，15 秒单条生成，提示词迭代 v02→v07 后成片通过。完整复盘见 [case-log.md](references/case-log.md)，最终版提示词见 [examples/01-便利店猫咪店员-v07.md](examples/01-便利店猫咪店员-v07.md)。

## 判断是否适用

- **适用**：便利店场景 + 两只宠物店员（猫猫/狗狗）+ 便当加热剧情；用户提供宠物照片并要求做这个题材的视频。
- **变体**：狗狗版（小柴犬+大柴犬）、单只店员、不同语言对白、是否需要 BGM 等，都在本 Skill 范围内。
- **不适用**：其他场景或题材的短剧 → 使用 `ai-short-drama-director`；没有便利店店员题材的单镜头视频 → 使用普通视频生成工作流。

## 工作流

```text
收集输入（宠物照片 + 语言/时长/比例/猫版或狗版）
  → 确定角色配置（小店员/大店员/顾客手部）
  → 套用招牌剧情节拍表
  → 参数决策（时长整数、比例、模型、声音策略）
  → 提示词写作（七段式）
  → 生成与验收（抽帧检查）
  → 版本化迭代（只改被指出的问题）
```

## 1. 收集输入

- **宠物照片**：小店员（体型较小的猫/狗）一张、大店员（体型较大的猫/狗）一张，用于锁定真实外观特征（毛色、斑纹、体型）。照片只锁定外观，服装/站位由提示词指定。
- **猫版还是狗版**：明确角色物种；默认猫猫版（英短小店员+布偶大店员），狗狗版（小柴犬+大柴犬）。
- **约束确认**：对白语言（默认日语）、总时长（默认 15 秒）、画幅（默认 9:16）、是否要字幕（默认无）、声音偏好（默认无背景音乐仅对白+音效）。

## 2. 角色配置（标准三角色）

| 角色 | 职能 | 声线 | 画面出现方式 |
|---|---|---|---|
| 小店员（小猫/小狗） | 主角：问询、承诺、趴便当加热 | 稚嫩清脆的儿童/小孩声线 | 全程出镜，站在收银台后 |
| 大店员（大猫/大狗） | 前辈：后场整理货架 → 转身救场 → 抱下致歉 → 开盖吹气 | 成熟稳重的成年女声 | 开场只露背影，后场站地面上 |
| 顾客 | 配角：应诺、疑惑 | 低沉沉稳的成年男声 | 只露手和一点袖口，不露脸 |

声线之间必须有明显反差，否则生成结果会混音听不出角色。

## 3. 招牌剧情节拍表（默认 15 秒）

| 时间 | 画面与动作 | 台词/声音 |
|---|---|---|
| 0-2.5s | 小店员在收银台后招呼顾客，后场大店员背影整理货架 | 小店员：「いらっしゃいませ！このお弁当、温めますか？」 |
| 2.5-3.5s | 顾客手部触碰便当盒（只露手，不露脸） | 顾客：「はい。」 |
| 3.5-5.5s | 小店员点头承诺 | 小店员：「ちょっと待ってくださいね！」 |
| 5.5-8s | 小店员趴上便当盒加热；大店员背影转头 | 顾客：「えっ？」 |
| 8-10s | 大店员原地转身走向台前 | 无 |
| 10-12.5s | 大店员抱下小店员、致歉 | 大店员：「申し訳ございません、今すぐ温めますね。」 |
| 12.5-15s | 大店员开盖吹气，小店员歪头看 | 无 |

时长与台词可按用户要求调整；调整后时间轴仍用整数秒。

## 4. 场景与制服设定（固定模板）

- 场景：同一家日式便利店内部，自始至终只有这一个场景；中性设计，无任何品牌文字或 logo。
- 关键陈设：收银台台面一盒透明盖便当（无品牌文字）、黑色扫码枪、POS 机、微波炉、食品保温柜；后场货架、堆叠纸箱。
- 光线：暖黄色顶光为主光，右侧冷柜冷白色背景光。
- 制服：日式便利店绿色员工制服（帽子+上衣），大小店员同款。
- 连续性与机位：大店员所在后场与收银台同属一个连续空间；镜头始终朝向同一方向，机位连续不切换；画面不得跳切、不得出现新的空间。

## 5. 参数决策

- **时长必须是整数秒**：所有视频平台的生成读秒都是整数，不要出现 9.5/8.5。
- **画幅**：默认 9:16 竖屏。
- **单条 vs 多段**：优先**单条一次生成**（15 秒内）：衔接最丝滑、可整体配 BGM、避免跨段道具/场景漂移。必须分段时（超时长）：每段只承载一个主要节拍，完整台词不跨段截断；段间必须用上一段真实尾帧作下一段 0 秒首帧，并声明「道具外观、布局、光位以上一张图为准，不得改变」。
- **模型**：默认性价比最高档（如 seedance 2.0 fast）。分辨率/清晰度以该模型固定输出为准。
- **声音策略**：默认「无背景音乐，无 BGM，无配乐；仅保留对白与环境音效、动作拟音」。单条长段且用户明确要求时可以配氛围 BGM（音量不压对白）；多段拼接时各段都不配 BGM。

## 6. 提示词写作（七段式）

每条提示词按以下顺序组织：

1. **参考图说明**：`<图片N>` 对应小店员/大店员照片；外观锁定（毛色斑纹、体型）；绿色员工制服；初始站位（小店员收银台后、大店员后场地面上背对镜头）。
2. **场景**：同上「场景与制服设定」，显式写「同一家便利店内部，自始至终只有这一个场景」「机位连续不切换」。
3. **动作与对白**：严格按节拍表时间轴写，每段含：谁、动作、表情/语气、台词（原文语言用引号）。
4. **声线设定**：三角色独立声线（小店员=童声、大店员=成熟女声、顾客=低沉男声），显式要求反差。
5. **镜头**：9:16；中景、近景、特写交替（开场中景、趴便当低机位近景、抱下中近景、吹气特写）；写实毛质、柔和景深。
6. **声音**：对白语言 + 环境音效 + 动作拟音（便当盒轻响、爬动声、开盖声、吹气声、店内环境声）；BGM 策略。
7. **生成时长**：整数秒，单条还是分段。

### 提示词铁律（便利店题材，违反必出问题）

1. **不写平台名**：提示词里不要出现「面向 XX 平台」字样。
2. **时长整数**：所有分段与时间轴边界都用整数秒。
3. **多段承接用真实尾帧**：第二段必传第一段真实尾帧作 0 秒首帧；道具/布局/光位「以上一张图为准，不得改变」。
4. **声音落位准确**：顾客的「えっ？」必须落在小店员趴便当的节拍段里，不能挪到下一段（否则声音割裂）。
5. **站位防穿帮**：大店员写「双脚站在地面上」，明确禁止站在台面/操作台上——否则走动会出现「从台上下来」的穿帮。
6. **移动路径防场景跳变**：大店员写「原地转身、不离开后场、不穿过货架、不出现任何新的货架通道或走廊，同一画面内径直走向台前」；并声明「场景唯一、机位连续、不得跳切、不得出现新的空间」。模型容易把「穿过货架」拍成新的货架通道场景。
7. **声线必须有反差**：小店员童声 / 大店员成熟女声 / 顾客男声，三声线不能同类。
8. **无字幕、无水印、无品牌文字、无平台 UI**：写入镜头段。
9. **参考图锁定真实特征**：写「保留照片中的真实毛色斑纹」，防止模型泛化外貌。
10. **版本化迭代**：每次修改递增版本号（v02→v07），只改被指出的问题，未反馈部分保持原样。

## 7. 生成与验收

- 提交生成时使用真实参数：模型、时长（整数）、比例、参考图 URL（按提示词中的 `<图片N>` 顺序传入）。
- 生成后**主动抽帧**检查关键节拍段，重点排查：大店员转身/走动是否穿帮、是否出现新场景（场景跳变）、便当盒外观与开合状态是否变化。
- 检查声音：对白是否落在正确节拍、三声线是否区分、有无意外背景音乐。
- 交付成片前用文字列出检查结论与问题时间码；有问题先修提示词再重生成，不直接把问题成片交付。

## 8. 迭代

- 用户反馈 → 定位到具体时间码/具体问题 → 只修改对应提示词段落 → 递增版本号 → 重新生成。
- 保留每个版本的提示词文件（`提示词_完整版_vXX_*.md`），便于回溯。
