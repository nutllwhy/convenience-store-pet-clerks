# 案例复盘：便利店猫咪店员（v02 → v07）

本案例是「便利店宠物店员」系列的第一个完整落地案例，也是本 Skill 提示词铁律的来源。复刻对象：一段「两只柴犬在便利店当店员」的视频。用户要求：主角换成自己的两只猫——英短猫=小店员、布偶猫=大店员，全程日语对白。

## 案例参数

- 模型：seedance 2.0 fast（性价比最高档；输出固定 720p，生成侧无法再降清晰度）
- 时长：15 秒单条生成（最终版）；早期为 9.5s+8.5s 两段拼接
- 画幅：9:16 竖屏
- 素材：英短照片 + 布偶照片各一张（锁定毛色斑纹）；原视频截图仅作剧情/调度参考
- 对白：日语（小店员 2 句、顾客 2 句、大店员 1 句）
- 声音：无字幕；最终版配轻松便利店氛围 BGM + 环境音效 + 动作拟音

## 模型行为观察（seedance 2.0 fast）

1. 「穿过货架/走廊」这类移动描述容易触发**新场景生成**（货架通道），导致场景跳变。修法：原地转身 + 同一画面内径直走向 + 显式「场景唯一、机位连续」。
2. 角色站在台面/操作台上时，后续走动会被生成为「从台上跳下/下来」。修法：明确「双脚站在地面上」。
3. 同一段内多个角色若声线描述相近（都是女声），生成结果声线会混在一起。修法：每个发声角色独立声线，反差越明显越好（童声 vs 成熟女声 vs 男声）。
4. 两段分别生成时，即使提示词完全一致，道具（便当盒）与环境的细节也会漂移。修法：段间用真实尾帧承接，并声明「以上一张图为准，不得改变」。
5. 单条一次生成比多段拼接衔接更丝滑，且只有单条才能整体配 BGM 不割裂。

## 对提示词铁律的溯源

| 铁律 | 来源反馈 |
|---|---|
| 不写平台名 | 用户：「提示词里面不要写面向 XX 平台」 |
| 时长整数 | 用户：「所有视频平台的视频生成，读秒都是整数」 |
| 真实尾帧承接 | 用户：「拿第一张生成的效果作为第二张的分镜参考，才能把片段连起来」 |
| 声音落位准确 | 用户：「客户的诶那一声放在第二个视频里，声音不太一致」 |
| 站位防穿帮 | 用户：「整理货架的小猫不能站在桌台上，不然会有莫名其妙下来的姿势，很容易穿帮」 |
| 移动路径防跳变 | 用户：「布偶猫往前走的时候莫名其妙出了一个新的场景，正常它转身就行了」 |
| 声线反差 | 用户：「两只猫声音没有反差；顾客最好用男声，现在三个女声混在一起」 |
