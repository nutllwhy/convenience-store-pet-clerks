## 二、七段式提示词骨架

```text
# 提示词_完整版_vXX（便利店宠物店员 · <N> 秒）

> 图生视频 / 参考生视频。输入素材：<图片1> = <小店员照片描述>；<图片2> = <大店员照片描述>。
> 用法：把下方【提示词正文】整体复制到提示词框；<图片1> 对应上传 <小店员照片>，<图片2> 对应上传 <大店员照片>。画幅 9:16 竖屏，时长 <N> 秒，单条一次生成。

## 提示词正文

<图片1> 作为主角<小店员物种>小店员的外貌毛色参考：<真实外观特征>，保留照片中的真实毛色斑纹。它身穿日式便利店绿色员工制服（帽子+上衣），站在便利店收银台后。

<图片2> 作为配角<大店员物种>大店员的外貌毛色参考：<真实外观特征>，保留照片中的真实毛色斑纹。它身穿同款日式便利店绿色员工制服（帽子+上衣），一开始在后场**站在地面上**、双脚着地，背对镜头整理货架上的商品。

场景：同一家便利店内部，自始至终只有这一个场景，画面不得跳切、不得出现新的空间。中性设计的便利店，无任何品牌文字或 logo。收银台台面摆着一盒透明盖便当（无品牌文字），背景有黑色扫码枪、POS 机、微波炉与食品保温柜；后场有货架、堆叠纸箱。光线为暖黄色顶光为主光，右侧冷柜冷白色背景光，明亮柔和。大店员站在后场的地面上整理货架，与收银台同属一个连续空间，镜头始终朝向同一个方向，机位连续不切换。

动作与对白（按时间顺序，一条连续 <N> 秒）：
- 0-2.5 秒：中景。<小店员>站在收银台后，前爪搭台面，身体微微前倾，热情地朝画面右侧顾客方向开口说话，语气热情上扬、稚嫩清脆如小孩子：「いらっしゃいませ！このお弁当、温めますか？」；后场左侧，<大店员>**双脚站在地面**上，背对镜头整理货架商品，只露出背影。
- 2.5-3.5 秒：特写。画面右侧出现顾客的手部（只露手和一点袖口，不出现人脸），指尖轻轻触碰便当盒盖，传来简短沉稳的男声应声：「はい。」
- 3.5-5.5 秒：<小店员>听完，眼神变亮、郑重点头，用稚嫩童声轻快承诺：「ちょっと待ってくださいね！」随后视线转向面前的便当盒。
- 5.5-8 秒：<小店员>从收银台后爬上台面，整个身体趴到透明盖便当盒上，前爪环抱盒体、脸颊贴盒盖、双眼微闭，认真地把自己的身体当作加热工具；与此同时，顾客（仍只露手部）发出短促上扬的男声疑惑声：「えっ？」后场的<大店员>背影听到声音，停下动作缓缓转头。全程仍是同一个后场位置，画面不切换。
- 8-10 秒：<大店员>在原地转身（不离开后场、不穿过货架、不出现任何新的货架通道或走廊），它原本就**双脚站在地面上**，转身后直接迈步，在同一画面内径直向台前走来，目光落在趴在便当盒上的<小店员>身上，微微愣住。镜头保持连续，不得切景、不得换空间。
- 10-12.5 秒：<大店员>走到台前，前爪轻柔地环住趴在便当盒上的<小店员>，把它整个抱离便当盒、放到台面一侧，动作温柔；放好后低头向顾客方向致意，用成熟沉稳的成年声线郑重开口：「申し訳ございません、今すぐ温めますね。」
- 12.5-15 秒：<大店员>俯身，前爪打开便当盒的透明盖，低头朝盒内轻轻吹气；台面一侧的<小店员>歪头好奇地看着；画面定格约 0.6 秒温暖收尾。

声线设定（重要，务必区分开）：
- <小店员>：**稚嫩清脆的儿童/小孩声线**，语气活泼上扬，像小孩子说话。
- 顾客（只露手部，不露脸）：**低沉沉稳的成年男声**，两句都简短克制。
- <大店员>：**成熟稳重的成年女声**，语气温柔郑重，与<小店员>的童声形成明显反差。

镜头：竖屏 9:16。中景、近景、特写交替（开场中景交代两只店员与场景，趴便当给低机位近景，抱下给中近景，开盖吹气给特写）；写实毛质、柔和景深；无字幕、无水印、无品牌文字、无平台 UI。全程机位连续、场景唯一，禁止出现新的空间或场景跳变。

声音：<BGM 策略，默认"无背景音乐，无 BGM，无配乐">；保留 <对白语言> 对白与便利店环境音效、动作拟音（如便当盒轻响、爬动声、开盖声、吹气声、店内环境声）。

生成时长：<N> 秒，单条一次生成。
```

## 三、单条 15 秒完整版范例

通过验收的最终版（v07）全文见 `../examples/01-便利店猫咪店员-v07.md`，新案例直接按骨架填充即可。要点回顾：

- 两个角色各一张参考图，开头说明上传顺序；
- 场景显式声明「同一家便利店内部，自始至终只有这一个场景」「机位连续不切换」；
- 大店员写「双脚站在地面上」；
- 移动写法「原地转身、不离开后场、不穿过货架、不出现任何新的货架通道或走廊，同一画面内径直向台前走来」；
- 声线设定单独成段，三声线明确反差；
- 时间轴每段写明动作 + 表情 + 语气 + 台词。

## 四、多段拼接版范例（尾帧承接写法）

适用：总时长超过单条上限，或明确要求分段生成再拼接。

### SEG001（第一段）写法要点

- 结尾必须是**可承接的定格**（如「小店员趴在便当盒上」定格约 1 秒收尾）。
- 文件末尾附「尾帧承接说明」：

```text
## 尾帧承接说明

本段结尾定格为「<小店员>整个趴在透明盖便当盒上、前爪环抱盒体」的画面。生成后用该真实尾帧作为片段二 SEG002 的 0 秒首帧输入，以锁定便当盒外观、店内布局与光位完全一致。
```

### SEG002（第二段）写法要点

- 输入素材除大店员照片外，**必传 SEG001 真实尾帧**，放在靠后编号（如 `<图片2>`）。
- 提示词开头声明尾帧基准地位：

```text
<图片2> 作为本段 0 秒首帧和画面基准：上一段结尾 <小店员> 整个趴在透明盖便当盒上的画面。便当盒外观、店内货架与收银台布局、暖黄顶光与右侧冷柜冷白背景光、光位全部以上一张图为准，不得改变。
```

- 0 秒起的动作从首帧延续，不重新描述环境。
- 声音：本段不写 BGM；台词只放本段真实发生的（如 SEG002 只有大店员一句致歉）。
- 每段时长整数秒，时间轴边界整数化。

### 多段版常见错误（真实案例）

| 错误 | 后果 | 正确写法 |
|---|---|---|
| SEG002 不带 SEG001 尾帧 | 便当盒外观、店内环境两段不一致 | 必传真实尾帧作 0 秒首帧 |
| 顾客「えっ？」写在 SEG002 | 疑惑声与画面错位、声音割裂 | 落在 SEG001 趴便当节拍内 |
| SEG002 开头放「手停在便当上」特写 | 画面突兀、无法与上一段衔接 | 从尾帧定格直接延续 |
| 提示词写「面向 XX 平台」 | 平台绑定、不可通用 | 不写平台名 |
| 时长 9.5/8.5 秒 | 平台无法精确设置 | 全部整数秒 |

## 五、提交前必检清单

逐项核对，任一不满足都要先修：

- [ ] 提示词不含任何平台名/平台 UI 字样
- [ ] 所有时长与时间轴边界均为整数秒
- [ ] 多段版：第二段必传第一段真实尾帧，并声明「以上一张图为准，不得改变」
- [ ] 顾客「えっ？」落在小店员趴便当的节拍段
- [ ] 大店员站在地面上，不站在台面/操作台上
- [ ] 大店员移动写明「原地转身、不穿过货架、同一画面内走向台前」，且声明场景唯一、机位连续
- [ ] 三角色声线独立且相互有反差（童声/成熟女声/男声）
- [ ] 写「无字幕、无水印、无品牌文字、无平台 UI」
- [ ] 参考图描述写「保留照片中的真实毛色斑纹」
- [ ] 生成参数与提示词一致：模型、时长、比例、参考图顺序
